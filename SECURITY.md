# Статус бинарных сборок

## v1.2.1: распространение приостановлено

Microsoft Defender определил бинарную сборку как **`Trojan:Win32/Wacatac.B!ml`**. Срабатывание зарегистрировано для EXE и EXE внутри ZIP, а также воспроизводится при чтении локальной копии. Релиз v1.2.1 переведён в черновик до выяснения причины.

**Ложное срабатывание пока не подтверждено.** Не отключайте антивирус, не добавляйте исключения и не восстанавливайте этот EXE из карантина для запуска. Ранее опубликованные версии не проверены как безопасная замена.

### Что известно

- SHA-256 сборки из отозванного релиза: `2f6528d957f13f486a05cd2a176c0ef72b0d956ad3a564f1e5765e82b88b9e68`.
- SHA-256 закреплённого архива ExifTool 13.59 x64 совпал с использованной официальной загрузкой: `577257dd22baebee77157d905792d6ed2c5916cd03aa627f40b2175db12110ac6`.
- Подпись локального системного компилятора Microsoft C# проверена как действительная.
- Приложение и использованный Windows-launcher ExifTool не имеют Authenticode-подписи. Наличие неподписанного вложенного EXE и распаковки во временную папку может быть фактором эвристики, но причина срабатывания не установлена.
- Функциональные тесты и успешная сборка CI проверяют поведение программы, а не отсутствие вредоносного ПО.
- Настройки Defender и карантин в ходе проверки не изменялись. Личные фото, JSON и журналы Defender не отправлялись в сторонние сервисы.

Новый хеш, упаковка в другой архив или переименование EXE не считаются устранением обнаружения. До возобновления распространения требуется проверка причины и вердикт поставщика антивируса.

Официальная форма Microsoft для анализа программного файла: https://www.microsoft.com/en-us/wdsi/filesubmission

Решение Microsoft по этому файлу пока не получено. Внешняя антивирусная сертификация и доверенная подпись приложения не заявляются.
